Pokedex App ⚡️

A sleek and responsive Pokemon encyclopedia built with React and PokeAPI. This project was developed to coding journey to master asynchronous data fetching and modern UI components.

 🚀 Features
* Search & Filter: Find your favorite Pokemon instantly.
* Detailed Stats: View base experience, types, abilities, and high-quality sprites.
* Mobile First: Fully responsive design for browsing on any device.

## 🛠 Tech Stack
* React.js (Functional Components, Hooks)
* CSS3 (Custom Styling / Flexbox)
* PokeAPI (REST API)
* JavaScript (ES6+)
